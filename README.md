# Adare Restaurant Website

This project is a responsive webpage for **Adare Restaurant**, showcasing the restaurant's services, menu, contact information, and location on a map. The webpage is designed using HTML and CSS to provide a visually appealing and user-friendly interface.

## Features:
- **Header Section:** Displays the restaurant's logo.
- **Navigation Menu:** Contains links to different sections such as Home, Menu, Order Online, Gift Voucher, Catering, and Contact.
- **Text Section:** Describes the restaurant's services and offers a call-to-action for reservations.
- **Map Section:** Displays an embedded Google Map showing the restaurant's location.
- **Footer Section:** Provides contact details and copyright information.

## Technologies Used:
- HTML5
- CSS3 (with responsive design)
